# Archived in 2026

Written by `work-order.sh`. Tickets that left the active tree during 2026, one file each,
named exactly as they were while active.

Read one to see what was asked for, which acceptance criteria were observed and what was
observed for each, and either the merge SHA that landed it or the reason it was cancelled.
The `Outcome` block at the bottom is the only part added after the work stopped.

Filed here by `close` and `cancel`, never by hand. What the archive is and why it is
immutable is one level up in [../README.md](../README.md).
